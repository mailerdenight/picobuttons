# ピコボタン / Pico Buttons

iOS 17+向けの多言語レトロ電子音玩具。28種類のオリジナル音を、4列×7行のパッドで鳴らします。

## 収益化と広告設定

無料版は画面下のバナーと、自然な区切りだけで表示するインタースティシャルを使用します。App Open広告・リワード広告は実装しません。インタースティシャルは初回起動後120秒、直近の広告から8分、直近のパッド操作から5秒の各条件を満たし、40回以上の再生後かつ音声が停止した場合にのみ候補になります。候補となる箇所は設定を閉じた時、カテゴリ変更時、再生の区切りです。

AdMobリクエストは子供向け年齢処理、一般向けコンテンツ評価、非パーソナライズを有効にします。公開前にAdMob管理画面とApp Store Connectの年齢レーティング・プライバシー回答も、この子供利用前提の運用に合わせて確認してください。テスト用のApp ID／広告ユニットID／プライバシーポリシーURLを本番値へ置き換えるまでは公開できません。

買い切りの `Pico Buttons Pro`（non-consumable、ID: `com.ac.picobuttons.pro`）はすべての広告を外します。購入・復元・保留中の購入・購入状態の変更はStoreKit 2で処理します。ローカルテストには `PicoButtons/Resources/Configuration.storekit` をXcodeの実行スキームで選択してください。本番公開前に、同じ商品IDのnon-consumable商品をApp Store Connectで作成する必要があります。
